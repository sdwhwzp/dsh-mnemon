# v0.5.36: Skill Review Fixes and Settings Controls

[简体中文](../../zh-CN/releases/v0.5.36.md) | **English**

This patch release includes the reviewed changes in #355, #495, #497, #498 and #499.

- **Skill reviews:** sort a copy of open suggestions so two or more pending suggestions no longer stop a review with a frozen-array error before the model call.
- **Suggestion controls:** independently enable new-skill suggestions and improvements to existing skills. Both default to enabled under the existing self-evolution switch, preserving older configurations. Admission rechecks the current switches; existing suggestions remain available for manual handling.
- **Custom data directories:** on a local host with DSH's native directory-picker capability, choose a folder beside the existing path field. The result stays a draft until Apply. Other hosts retain manual input. Changing the path uses the existing storage behavior and does not move, copy or delete existing data.
- **DSH 0.2.1-rc.3:** allow six seconds for the official API-key model directory, accommodating DSH's five-second network budget. Other Providers keep the three-second limit. CI now also tests the installed rc.3 host.
- **OpenViking guidance:** document text-only writes and explain that a configured multimodal embedding model may remain in use when it accepts text. Image and attachment support remains tracked in open issue #453.

## Upgrade and compatibility

Supported hosts are DSH **0.2.0-rc.2**, **0.2.1-rc.2** and **0.2.1-rc.3**. From v0.5.35, use **Memory System → Status → Check versions → Update**, then restart DSH. For an exact WebUI installation:

```sh
dsh plugin --profile web add dsh-mnemon@0.5.36
```

For older installations and the desktop app, follow [Compatibility and upgrades](../reference/compatibility.md) and [Installation](../guides/installation.md).

No memory migration is required. Storage scopes and default paths retain their existing meaning. The directory picker is optional and has the same manual-input fallback as before. On downgrade, older versions ignore the new suggestion-type flags and continue to follow the existing self-evolution master switch.
