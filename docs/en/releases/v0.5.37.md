# v0.5.37: Skill Models, Runtime Limits and Reliable Status

[简体中文](../../zh-CN/releases/v0.5.37.md) | **English**

This patch release includes the reviewed changes in #503, #508, #510, #511, #513, #514 and #517.

- **Skill task models:** choose the model for drafting and backtesting, with page defaults and individual overrides. Preserve the selected route and its reasoning settings, rerun baselines for explicit model selections, recover interrupted drafting suggestions, and keep active draft links usable.
- **Runtime capacity:** edit user-profile and working-memory limits in Settings, with Apply/Discard and byte-range validation. Existing defaults and stored entries are preserved; lowering a limit does not delete entries.
- **Evolution scrolling:** scroll the suggestion list and detail independently on wide screens, reset detail position when selecting another suggestion, and contain boundary scrolling. Narrow screens retain their stacked layout and normal page scrolling.
- **Embedding status:** distinguish a reachable embedding service from a usable selected model, and distinguish model availability from stored-vector coverage. Verified model checks require Mnemon CLI 0.2.13 or newer; older CLIs are reported as needing an upgrade for verification.
- **Extension and build guidance:** demonstrate deferred SDK imports for optional Sources and verify their missing-Host behavior. Standalone pnpm executables run directly during build verification.

## Upgrade and compatibility

Supported hosts are DSH **0.2.0-rc.2**, **0.2.1-rc.2** and **0.2.1-rc.3**. From v0.5.36, use **Memory System → Status → Check versions → Update**, then restart DSH. For an exact WebUI installation:

```sh
dsh plugin --profile web add dsh-mnemon@0.5.37
```

No existing memory migration is required. The new Skills model preferences are additive. Skills 0.5.4 requires Starter **0.5.37 or newer within 0.5.x**, which supplies its model-catalogue SDK and Host behavior. Upgrade through the Starter's pinned composition; a rollback to Starter 0.5.36 must also restore Skills 0.5.3.

Memory Spaces and Provider integration architecture is unchanged. The proposed Hermes-like integration is research only and is not part of this release. Image and attachment support remains tracked in #453.
