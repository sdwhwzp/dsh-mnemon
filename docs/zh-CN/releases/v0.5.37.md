# v0.5.37：技能模型、运行时容量与可靠状态

**简体中文** | [English](../../en/releases/v0.5.37.md)

本补丁版本包含已评审的 #503、#508、#510、#511、#513、#514 与 #517。

- **技能任务模型：**为草拟和回测选择模型，支持页面默认值与单项覆盖。保留所选路由及其推理设置，显式选择模型时重新运行基线，恢复中断的草拟建议，并保持活动草案链接可用。
- **运行时容量：**在设置中编辑用户档案与工作记忆容量，支持应用、放弃和字节范围校验。保留现有默认值与记录，调低容量不会删除已有记录。
- **演进页面滚动：**宽屏中建议列表与详情独立滚动，切换建议时重置详情位置，并阻止边界滚动带动外层页面。窄屏保留上下布局与正常页面滚动。
- **Embedding 状态：**区分服务可连接与所选模型可用，也区分模型可用性与已保存向量的覆盖率。验证模型需要 Mnemon CLI 0.2.13 或更新版本；旧 CLI 会提示需要升级后才能验证。
- **扩展与构建指引：**演示可选 Source 如何延迟导入 SDK，并验证缺少 Host 时的行为。构建验证直接运行独立 pnpm 可执行文件。

## 升级与兼容性

支持 DSH **0.2.0-rc.2**、**0.2.1-rc.2** 与 **0.2.1-rc.3**。从 v0.5.36 升级，使用**记忆系统 → 状态 → 检查版本 → 更新**，随后重启 DSH。WebUI 精确版本安装命令：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.37
```

现有记忆无需迁移。新增的技能模型偏好为附加字段。Skills 0.5.4 需要 **0.5.x 中的 Starter 0.5.37 或更新版本**，以使用其模型目录 SDK 和 Host 行为。请通过 Starter 的固定组件组合升级；回退到 Starter 0.5.36 时，也必须恢复 Skills 0.5.3。

Memory Spaces 与 Provider 接入架构保持不变。拟议的 Hermes-like 接入仍处于研究阶段，不包含在本次发布中。图片与附件支持继续由 #453 跟踪。
