# v0.5.36：技能复盘修复与设置控制

**简体中文** | [English](../../en/releases/v0.5.36.md)

本次补丁版本包含经过审查的 #355、#495、#497、#498 和 #499。

- **技能复盘：** 对待处理建议的副本排序，修复存在两条及以上建议时，复盘在调用模型前因冻结数组报错而中断的问题。
- **建议控制：** 分别控制新建技能建议与已有技能改进建议。在原有自进化总开关下，两项默认开启，保持旧配置行为。接纳建议时重新检查当前开关；已有建议仍可手动处理。
- **自定义数据目录：** 本地宿主具备 DSH 原生目录选择能力时，可在现有路径输入框旁选择文件夹。结果先进入草稿，点击应用后才保存；其他宿主继续手动输入。修改路径沿用已有存储行为，不搬移、复制或删除原有数据。
- **DSH 0.2.1-rc.3：** 官方 API Key 模型目录允许等待六秒，兼容 DSH 默认五秒联网预算。其他 Provider 仍为三秒。CI 新增已安装 rc.3 宿主验证。
- **OpenViking 指引：** 明确只支持文本写入，并说明已配置的多模态 embedding 模型只要接受文本即可继续使用。图片与附件支持仍由开放的 #453 跟踪。

## 升级与兼容性

支持 DSH **0.2.0-rc.2**、**0.2.1-rc.2** 和 **0.2.1-rc.3**。从 v0.5.35 升级，使用**记忆系统 → 状态 → 检查版本 → 更新**，随后重启 DSH。精确安装到 WebUI：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.36
```

较旧版本和桌面版的安装方法，见[兼容性与升级](../reference/compatibility.md)和[安装指南](../guides/installation.md)。

无需迁移已有记忆。存储范围与默认路径含义不变。目录选择器为可选能力，保留原有手动输入方式。降级后，旧版本会忽略新增的建议类型开关，并继续遵循原有自进化总开关。
